🛠️ Your First Steps After Download

Once the application is open, you will see a familiar window with a menu bar at the top, a large editing area in the middle, and a file list on the side. Here is a simple way to get comfortable with it in the first ten minutes:

  1. Choose File → New to create a blank document and start typing.
  2. Choose File → Open to load an existing file from your computer and see how it is displayed.
  3. Press Ctrl + F to search inside the document. This is the tool you will use most often.
  4. Press Ctrl + H to replace a word or phrase across the whole file.
  5. Use the View menu to turn the side panel and status bar on or off until the layout feels right.
  6. Save your work with Ctrl + S — a habit worth forming right away.

Nothing you do while exploring is permanent. You can close a file without saving, reopen it, and try again.

💡 Tips for a Smooth Experience

  • Keep the program in a folder you will remember, so future updates are easy to find.
  • Use a separate folder for your projects and open files from there — it makes backup and comparison much simpler.
  • Turn on automatic line numbers to make it easier to locate errors reported by other tools.
  • Before making large changes, save a second copy of the file. The comparison tool can then show you exactly what you altered.
  • If a file looks unusual on screen, check the encoding option in the bottom status bar and switch it to match the file.
